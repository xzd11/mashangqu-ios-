# v1.1.0 · 已取记录、驿站分组与隐私增强

> 社区编译版本，使用 AI 编写。仅在 iPhone 15 上验证适用，其他机型尚未验证；需自行签名安装。

## ✨ 本次更新

- **已取记录与撤销**：快递页新增「待取 / 已取」切换，支持提示中的快捷撤销和历史记录恢复。撤销恢复待取记录，旧取件码已清除，需要重新查询；不修改平台取件状态。记录按账户隔离，兼容旧版已取标记。
- **按驿站分组**：同一站点包裹集中展示，可按需关闭。
- **登录状态检查**：「我的」页面支持单独或批量联网检查，区分登录过期、需要平台验证、请求频繁、网络失败及平台异常，提供重新登录或重试入口。
- **应用内更新检查**：查看 GitHub 正式版更新说明，跳转发布页下载 IPA；有账户时每日自动检查一次，也可手动检查。安装仍需用户自行签名。
- **后台隐私遮挡**：应用离开前台活动状态时，原生遮罩覆盖窗口；返回前台后恢复内容。
- **脱敏诊断导出**：通过系统分享菜单导出版本、平台状态、缓存数量、HTTP 状态与耗时等诊断信息。最多保留 200 条内存事件，不记录 Cookie、Token、手机号、运单号、身份码、取件码或原始请求内容，不自动上传。

## 📲 安装与升级

- 下载 Assets 中的 `mashangqu-ios-v1.1.0.ipa`，无需解压，自行签名安装。
- 版本 1.1.0（构建 13），ARM64，最低系统配置 iOS／iPadOS 15.0。
- 沿用相同签名身份及 Bundle ID `ink.mashangqu.ios` 覆盖安装，可延续本机数据。
- `mashangqu-ios-v1.1.0-source.zip` 为完整 iOS 源码包；仓库源码位于 `ios/`。
- `SHA256SUMS` 提供安装包与源码包的 SHA-256 校验值。

## 🧪 验证范围

- 用户反馈本版测试无问题；仅在 iPhone 15 上验证适用。
- 六项功能的模拟接口与浏览器检查通过，覆盖撤销回滚、账户隔离、旧记录迁移、更新链接校验、日志脱敏及页面隐私遮挡。
- 拼多多扫码与内置验证、菜鸟查码、已取功能和横向全屏条码回归通过；ARM64 原生编译及对象布局检查通过。
- 自动化环境没有运行 iOS 真机；用户设备反馈与模拟测试结论分别记录，不代表其他设备或平台接口未来持续兼容。
- 京东暂不支持快递列表；菜鸟查询使用快递运单号，结果以当前账户可访问的平台数据为准。
