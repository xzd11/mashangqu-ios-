# v1.0.0 · 码上取 iOS 社区编译版本

> 使用 AI 编写，仅在 iPhone 15 上验证使用，其他机型尚未验证。需自行签名后安装。

## 新增功能

- 五平台身份码集中展示与切换。
- 身份条形码横向全屏放大，支持过期提示。
- 快递列表聚合、筛选与相同运单合并。
- 输入快递运单号，通过已登录的菜鸟账户查询取件码。
- 快递卡片新增「通过菜鸟查询取件码」按钮，显示结果与来源。
- 可配置前台自动刷新。

## 修复与调整

- 修复启动阶段闪退。
- 调整拼多多、顺丰和京东登录页面布局。
- 完善身份码刷新，菜鸟身份码使用条形码展示。
- 关闭主界面双击和捏合误缩放，移除测试标识。

## 安装与兼容性

- 下载附件 `mashangqu-ios-v1.0.0.ipa`，自行签名后安装，无需解压。
- 版本 1.0.0（构建 9），ARM64，最低配置 iOS／iPadOS 15.0。
- 仅在 iPhone 15 上完成用户验证，其他机型及系统版本未验证。
- 更新建议沿用相同签名身份与 Bundle ID `ink.mashangqu.ios`。

## 使用说明

京东目前支持身份码，暂不支持快递列表。菜鸟查询需要登录对应账户，使用快递运单号而非购物订单号，结果以平台返回的数据为准；无法从脱敏信息还原完整取件码。
