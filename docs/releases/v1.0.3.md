# v1.0.3 · 拼多多内置验证与已取功能

> **社区编译版本，使用 AI 编写。此前版本仅在 iPhone 15 上验证使用，其他机型尚未验证。需自行签名安装。**

本次发布包含自 v1.0.0 以来的累计更新。

## ✨ 1.0.3：软件内统一样式验证

- 拼多多扫码后的短信验证码、文字单选／多选和图片选择题改用应用内验证界面，与软件配色、卡片和按钮保持一致。
- 用户手动输入验证码或选择答案；错误时提示重试，选择题按服务端要求加载下一题。
- 验证通过后继续原扫码授权会话，保存登录凭据。
- 滑块、拼图、未知类型或内置验证失败时，保留「改用官方验证页面」入口。
- 临时验证密钥仅保存在内存，关闭窗口后清理；取消后不会保存迟到请求返回的登录结果。

## 📷 1.0.2：拼多多扫码授权登录

- 移植上游 AUTH_LOGIN 扫码登录流程，默认入口改为「扫码登录」。
- 支持保存二维码／系统分享，方便在同一台手机上使用拼多多扫一扫的相册识别。
- 二维码过期自动刷新，关闭窗口后停止轮询。
- 不走普通手机号登录流程；是否保持拼多多客户端在线仍需真机确认。

## ✅ 1.0.1：已取与本机取件码删除

- 快递卡片与独立查码结果新增「已取」按钮。
- 点击后删除本机取件码，并从待取列表移除。
- 本机保存按平台账户区分的完成标记，刷新、重新启动后不恢复旧码。
- 保存失败时恢复原记录并提示失败。
- 此操作只影响本机，不修改菜鸟或快递平台上的取件状态。

## 📲 安装与升级

- 下载下方 Assets 中的 `mashangqu-ios-v1.0.3.ipa`，无需解压，自行签名后安装。
- 版本：1.0.3（构建 12），ARM64，最低系统配置 iOS／iPadOS 15.0。
- 建议沿用相同签名身份与 Bundle ID `ink.mashangqu.ios` 覆盖安装。
- `mashangqu-ios-v1.0.3-source.zip` 为完整 iOS 源码包；仓库源码同步放在 `ios/`。
- `SHA256SUMS` 提供 IPA 和源码包的校验值。

## 🧪 验证范围

- 实际匿名请求已成功生成拼多多授权二维码（HTTP 200）。
- 扫码流程、验证加密信封、短信与选择题、错误处理、取消隔离及「已取」功能已通过模拟接口检查，ARM64 编译和对象布局检查通过。
- **新增内置验证、二维码保存、完整扫码授权及客户端是否保持在线，仍需真实账户在 iPhone 上确认。** 未将模拟测试视为真机验证。
- 京东仍暂不支持快递列表；菜鸟查码使用快递运单号而非购物订单号，结果以当前账户可访问的平台数据为准。
